# 🚀 My Plan Tracker (نسخه تحت وب و موبایل PWA)

یک سامانه مدرن، ریسپانسیو و لمسی برای پایش عادات روزانه و برنامه‌ریزی ماهانه با پشتیبانی از تقویم شمسی، قفل امنیتی پین‌کد و قابلیت اجرای آفلاین (PWA).

## 🌐 نحوه میزبانی رایگان روی GitHub Pages (در کمتر از ۲ دقیقه)

این برنامه کاملاً ایستا (Static) طراحی شده و بدون نیاز به هیچ سرور یا هزینه‌ای روی **GitHub Pages** میزبانی می‌شود:

### مرحله ۱: ایجاد ریپازیتوری در گیت‌هاب
1. وارد حساب کاربری خود در [GitHub.com](https://github.com) شوید.
2. روی دکمه **New Repository** کلیک کنید.
3. نام مخزن را دقیقاً بگذارید: `my-plan-tracker` (یا هر نام دلخواه دیگر).
4. وضعیت را روی **Public** قرار دهید و روی **Create repository** کلیک کنید.

### مرحله ۲: آپلود فایل‌های این پوشه
فایل‌های موجود در این پوشه (`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, و آیکون‌ها) را داخل مخزن آپلود کنید:
* **از طریق سایت گیت‌هاب:** زدن دکمه `uploading an existing file` و کشیدن و رها کردن فایل‌ها.
* **یا از طریق خط فرمان Git:**
  ```bash
  git init
  git add .
  git commit -m "Initial commit of My Plan Tracker"
  git branch -M main
  git remote add origin https://github.com/<YOUR-USERNAME>/my-plan-tracker.git
  git push -u origin main
  ```

### مرحله ۳: فعال‌سازی هاست GitHub Pages
1. داخل مخزن خود در گیت‌هاب، به تب **Settings** بروید.
2. از منوی سمت چپ روی **Pages** کلیک کنید.
3. در بخش **Build and deployment**:
   * بخش Source را روی **Deploy from a branch** بگذارید.
   * زیر آن، Branch را روی **main** و شاخه را روی **/ (root)** بگذارید.
   * دکمه **Save** را بزنید.
4. پس از ۱ تا ۲ دقیقه، لینک سایت اختصاصی شما آماده است:
   ```
   https://<YOUR-USERNAME>.github.io/my-plan-tracker/
   ```

## 📱 نحوه تبدیل به اپلیکیشن روی گوشی (Add to Home Screen)

وقتی آدرس سایت بالا را روی مرورگر گوشی خود باز کردید:

### در گوشی‌های آیفون (iOS Safari):
1. سایت را در مرورگر **Safari** باز کنید.
2. دکمه **Share** (مربع با فلش رو به بالا در پایین صفحه) را بزنید.
3. گزینه **«Add to Home Screen»** (افزودن به صفحه اصلی) را انتخاب کنید.
4. دکمه **Add** را بزنید.
*از این پس یک آیکون اختصاصی و شیک مثل برنامه‌های اپ‌استور روی صفحه گوشی شما قرار می‌گیرد و بدون کادر مرورگر باز می‌شود.*

### در گوشی‌های اندروید (Chrome / Samsung Internet):
1. سایت را در مرورگر **Chrome** باز کنید.
2. روی منوی ۳ نقطه بالا سمت راست ضربه بزنید.
3. گزینه **«Install App»** یا **«Add to Home Screen»** را انتخاب کنید.
4. دکمه **Install** را بزنید.

## 💾 ذخیره‌سازی و پشتیبان‌گیری از اطلاعات
* تمامی تیک‌ها و پیشرفت‌های شما روی حافظه مرورگر دستگاه به صورت محلی و فوق‌العاده سریع ذخیره می‌شود.
* حتی اگر اینترنت قطع باشد، به لطف تکنولوژی **Service Worker (PWA)** برنامه آفلاین کار می‌کند.
* از بخش **تنظیمات ⚙️** می‌توانید هر زمان با زدن **«دانلود بکاپ (JSON)»** از اطلاعات خود خروجی بگیرید یا خروجی جدول **اکسل (CSV)** دریافت کنید.
